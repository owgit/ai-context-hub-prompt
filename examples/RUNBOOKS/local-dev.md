# Local Dev Runbook

## Purpose

Describe how local development is started across the mapped systems.

## Example Steps

1. Identify which repos are needed for the task.
2. Confirm local URLs and ports from `ENVIRONMENTS.md`.
3. Check env file names and required secret references.
4. Start only the services needed for the current task.
5. Record any local-only constraints as verified notes.

## Guardrails

- do not invent startup commands
- keep local and production clearly separated
- mark unknown setup steps as unverified
